# 와이어프레임

앱 화면을 클릭해 보는 HTML(`index-v2.html` 최신 — 화면 기준, `index.html` 이전 판 — 비교용으로 보존)과 그 데이터를 뽑는 스크립트(`export.py`). 두 판이 같은 `data.json`을 읽는다. 화면 구성의 근거는 원본 글 1~4편, 기능 범위는 [[치과 AX - 기능 정의]].

- 데이터: `make data` 뒤에 `make wireframe` → `data.json`(생성 DB에서 화면별로 뽑음. AI 결과 칸은 정답 라벨로 채운 예시라 커밋하지 않는다. 통화는 silver만, 물어보기 예시는 dev 문항만 — 판정 풀·test 정답이 보이면 사람 판정·평가가 오염된다. silver에는 자동 개선 재료·검증이 섞여 있어 사람 확인용이고 개선 에이전트 입력으로 쓰지 않는다. 일계표는 정답 저장소가 아니라 카드 합계 차이가 있는 날만 표시한다. 청구 전 점검·경영 리포트·지출 증빙은 정답 저장소를 쓰지 않고 규칙 값만, AI 칸은 자리로 둔다)
- 보기: `data.json`을 읽어야 해서 파일을 바로 열지 말고 이 폴더에서 `python -m http.server`로 연다
- 공유본: claude.ai 아티팩트(비공개)에 판마다 HTML과 `data.json`을 올려 둔다 — 데이터가 바뀌면 다시 뽑아 같은 아티팩트에 올린다
