# 옛 종이 차트 OCR 이관 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 종이 차트 스캔 이미지를 업스테이지 OCR·정보 추출로 읽어, 사람이 고치고 승인하면 EMR 차트에 "종이 차트 이관" 줄로 붙는 시연용 흐름.

**Architecture:** 샘플 PNG는 `demo/paper_charts/make.py`가 HTML을 그려 Playwright CLI로 찍는다. `backend/chart_ocr.py`가 업스테이지 두 API를 부르고 응답을 정리, `backend/emr_bridge.py`가 `ax_chart_imports`에 초안·승인을 쓴다. 새 포털 페이지가 이미지 + OCR 상자 + 항목 폼을 보이고, EMR 창 전자차트가 승인된 이관 줄을 합쳐 그린다.

**Tech Stack:** Python(FastAPI, sqlite3, httpx), 업스테이지 Document Digitization(OCR)·Information Extraction API, Next.js(Tailwind + shadcn/ui), Playwright CLI(샘플 찍기)

**Spec:** `docs/superpowers/specs/2026-11-18-chart-ocr-design.md`

> 작업 기록 — 모두 끝났다. 진행 중 바뀐 이름·동작(승인 본문 `chart_no`·`part`, `at: str`, `chart_imports` 키, `api._paper`, 날짜 교차검증, 정보 추출 → OCR + Sonnet 정리 등)은 [[치과 AX - 기능 정의]] §5 종이 차트 이관·[[치과 AX - 앱 설계]] §3b·§7.1·§9가 원본(정리 방식 비교는 [[치과 AX - AI 실험 기록]] §40)

- 쓰기는 `backend/emr_bridge.py`만, `ax_chart_imports`에만 — `emr_*`·`fin_*` 무변경, `backend/`는 `ground_truth/`·`generator/`·`evaluation/` import 금지

  - `words(ocr_resp: dict) -> list[dict]` — `{text, confidence, box: [x0, y0, x1, y1]}`(이미지 비율 0~1)
